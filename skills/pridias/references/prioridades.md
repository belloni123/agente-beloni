# Prioridades por tarefa

Escolha uma responsável por etapa. Skills e ferramentas precisam estar disponíveis na sessão; instruções locais e escolhas explícitas prevalecem. Não executar pipelines alternativos em paralelo por rotina.

| Entrega | Primeira escolha | Complemento quando necessário |
|---|---|---|
| Código em projeto com Bell | `bell-dev-os:bell-governance` e fase correspondente | Uma especialista da stack para requisito concreto; outros projetos seguem suas regras locais. |
| Bug sem causa conhecida | Investigação em [diagnostico.md](diagnostico.md), seguida do fluxo do projeto | Reproduzir, localizar causa, corrigir e verificar proporcionalmente. |
| UI e design | [criacao.md](criacao.md) | Uma responsável por direção visual; preservar marca e stack. |
| Copy comercial | `copymoney-copywriter` | `ze-marreta-vendedor` quando o pedido for estratégia comercial ou negociação. |
| Posts e carrosséis autorais | `social-editorial-studio` | `social-art-review` para conferir a arte renderizada. |
| Arquivos Google | Skill nativa `google-drive` do tipo de arquivo | O conector disponível determina as operações possíveis. |
| Arquivo local de documento, planilha, slides ou PDF | Skill nativa do formato | Não transformar o pedido em arquivo Google por padrão. |
| Auditoria de segurança | Skill de Codex Security correspondente ao escopo | Pentest com Strix somente no escopo de pentest solicitado e autorizado. |
| Busca pontual de código | Busca direta; Codebase Memory se indexado | `graphify` quando a entrega pedir mapa de relações. |
| Pesquisa | Busca direta para pergunta pontual | `intushub-daily-briefing` para curadoria recorrente; `scrapling-official` para construir coleta repetível. |
| Vídeo e áudio | Editor explicitamente escolhido e skill correspondente | `motion-editorial` para ritmo e continuidade; `intushub-motion` para técnica específica. CapCut somente com pedido explícito. |
| Motion em aplicativo | `effectcraft` ou skill do editor pedido | Não trocar o editor por rotina. |
| Biblioteca IntusHub | `intushub-biblioteca` quando o guia for citado ou necessário | Consultar o material como referência não exige reinstalar pacotes aposentados. |

Preserve a regra de áudio do usuário: “não mexer no áudio” mantém a faixa original intacta na entrega, por cópia quando possível. Não tratar, silenciar, trocar ou recomprimir por iniciativa própria.
